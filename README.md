# Accessible User Interface

A simple, accessible web UI demonstrating WCAG 2.1 AA best practices.

## Features

- Semantic HTML5 landmarks (`header`, `nav`, `main`, `aside`, `footer`)
- Skip-to-content link for keyboard users
- ARIA roles, labels, and live regions
- High-contrast colour scheme
- Fully keyboard-navigable controls
- Client-side form validation with accessible error messages

## Usage

Open `index.html` in any modern browser — no build step required.
